## How I build

```mermaid
flowchart LR
    A["Domain & requirements"] --> B["Typed contracts"]
    B --> C["Data & tools"]
    C --> D["Models / agents"]
    D --> E["Evaluation"]
    E --> F["Software delivery"]
    E -->|"Evidence & failure analysis"| B
```

I treat models as components of software systems, not substitutes for architecture. The surrounding system owns persistent state, permissions, deterministic computation, evidence, validation and failure behavior. In research, I distinguish numerical verification from real-world validation and keep experimental claims within their demonstrated scope.
